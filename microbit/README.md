# micro:bit側実装（フェーズ1）

マイクラカップ用プロジェクト「フィジカルAI」の、現実世界とMinecraftをつなぐ仕組みの一番下の層です。
BBC micro:bit v2上でMicroPythonを動かし、センサー値をUSBシリアルでPCへ送信し、PCからのコマンドでLED表示を変えます。

全体構成（今回実装するのは①のみ）：

```
① micro:bit (MicroPython)  --USBシリアル-->  ② PC上のNode.jsブリッジ（未実装）  --WebSocket-->  ③ Minecraft Education（未実装）
```

## 1. 使用センサーと送信プロトコル

送信は**200ms間隔**で行われ、1件ごとに改行(`\n`)区切りのテキストとしてUSBシリアル経由でPCに送られます。
ボーレートは **115200**。PC側のNode.jsブリッジはこの改行区切りテキストを1行ずつパースする想定です。

| センサー | 説明 | 送信フォーマット | 例 | 値の範囲・単位 |
|---|---|---|---|---|
| 加速度センサー | micro:bitの傾き（X/Y/Z軸） | `TILT,x,y,z` | `TILT,12,-980,58` | 各軸 -2048〜2047（ミリG） |
| 明るさセンサー | LEDマトリクスを流用した光センサー | `LIGHT,value` | `LIGHT,128` | 0（暗い）〜255（明るい） |
| 温度センサー | micro:bit内蔵の温度センサー | `TEMP,value` | `TEMP,24` | 摂氏（℃）の整数 |
| ボタンA/B | 押された瞬間だけイベント送信 | `BUTTON,A` または `BUTTON,B` | `BUTTON,A` | - |

補足：
- `TILT` / `LIGHT` / `TEMP` は200msごとに必ず送信されます。
- `BUTTON` はボタンが押された瞬間だけ送信されるイベント型です（押しっぱなしでも連射されません）。
- 明るさセンサーの読み取り中はLEDマトリクスが一瞬だけ消灯します（micro:bit標準の仕様。LEDと光センサーが同じ部品のため）。ICON表示中に読み取ると一瞬だけ画面がちらつくことがあります。

## 2. 受信コマンド一覧

PCからmicro:bitへ、改行区切りのテキストコマンドを送ることでLED表示を制御できます。

| コマンド | 動作 |
|---|---|
| `LED:ON` | LEDマトリクスを全点灯する |
| `LED:OFF` | LEDマトリクスを全消灯する |
| `ICON:HAPPY` | 笑顔アイコンを表示する |
| `ICON:SAD` | 悲しい顔アイコンを表示する |

- 上記以外の未知のコマンドを受信した場合は、**エラーを出さずに無視**します（プログラムは止まりません）。
- コマンドは1行1コマンドです。行末に`\n`（改行）を付けて送信してください。

## 3. micro:bitへの書き込み方法

### 方法A: Python Editor for micro:bit（Webブラウザ、おすすめ）

1. ブラウザで [https://python.microbit.org/](https://python.microbit.org/) を開く
2. 左上のメニューから「ファイルを開く」を選び、`microbit/main.py` を読み込む（またはコードを丸ごとコピー＆ペーストする）
3. micro:bitをUSBケーブルでPCに接続する
4. 「ダウンロード」ボタンを押すと `.hex` ファイルが生成される
   - ブラウザがWebUSBに対応している場合は「接続してフラッシュ」のようなボタンで直接書き込みも可能
5. `.hex` ファイルがダウンロードされたら、PC上で「MICROBIT」という名前のドライブ（USBメモリのように認識される）にファイルをドラッグ＆ドロップする
6. micro:bit上の黄色LEDが点滅し、書き込みが完了すると自動的に再起動する

### 方法B: Mu Editor（デスクトップアプリ）

1. [https://codewith.mu/](https://codewith.mu/) からMu Editorをインストールする
2. Muを起動し、モードを「BBC micro:bit」に設定する
3. `microbit/main.py` の内容をMuのエディタ画面に貼り付ける（またはファイルを開く）
4. micro:bitをUSBケーブルでPCに接続する
5. 画面上部の「Flash」ボタンを押すと自動的にビルド・書き込みが行われる

### 書き込み後の確認

- 起動直後、LEDにチェックマーク（✓）が一瞬表示されれば正常に起動しています（`main.py`内の`setup()`関数の動作）。

## 4. 動作確認方法（シリアルモニタでのテスト）

実機がなくても、以下の手順でPC側からセンサー値が流れてくるかを確認できます。

### Mu Editorのシリアルモニタを使う場合

1. Mu Editorで「Serial」ボタンをクリックするとシリアルモニタが開く
2. 200ms間隔で `TILT,...` `LIGHT,...` `TEMP,...` の行が流れてくれば正常
3. micro:bit上のボタンAまたはBを押すと `BUTTON,A` / `BUTTON,B` が表示される
4. シリアルモニタの入力欄に `LED:ON` と入力してEnterを押すと、LEDが全点灯するか確認できる（`ICON:HAPPY` / `ICON:SAD` / `LED:OFF` も同様）

### その他のシリアルターミナルを使う場合（PuTTY / screen / minicom / VS Code拡張など）

- ボーレートを **115200** に設定すること（他の値だと文字化けする、または何も表示されない）
- 改行コードは `\n`（LF）を送信できる設定にすること（`LED:ON\n` のように末尾に改行が必要）
- 例（Linux/macOSでscreenコマンドを使う場合）
  ```
  screen /dev/tty.usbmodemXXXX 115200
  ```
- 例（Windowsの場合はデバイスマネージャーでCOMポート番号を確認し、PuTTYなどでシリアル接続、ボーレート115200を指定）

## 5. つまずきやすいポイント

- **COMポート名の不一致**：Windowsでは `COM3` のように環境ごとに番号が変わります。デバイスマネージャーの「ポート（COMとLPT）」で `mbed Serial Port` を確認してください。macOS/Linuxでは `/dev/tty.usbmodem*` や `/dev/ttyACM*` のような名前になります。
- **ボーレートの不一致**：本プロジェクトは115200固定です。シリアルモニタ側の設定を必ず揃えてください（デフォルトが9600になっているツールが多いので注意）。
- **他のツールが同じCOMポートを掴んでいる**：Mu Editorのシリアルモニタとブラウザ版Python Editorなど、複数のツールで同時に同じmicro:bitに接続しようとすると「ポートが使用中」エラーになります。1つのツールだけ接続してください。
- **改行コードの違い（CRLF/LF）**：コマンド送信時、`\r\n`を送ると空行として扱われ無視されるだけなので害はありませんが、`\n`を含まないと1行として認識されずコマンドが実行されません。
- **LED点灯中に明るさセンサーを読むと一瞬ちらつく**：仕様です（3章の補足を参照）。誤動作ではありません。
- **`main.py`という名前・配置**：micro:bitは`main.py`という名前のファイルを自動実行します。他の名前で保存すると動きません。

## 6. なぜMicroPythonを選んだか

- **micro:bit公式が標準サポート**しており、Python Editor / Mu Editorなど無料のツールだけで書き込みまで完結し、学校のPC環境でも導入しやすい。
- **`microbit`モジュールがセンサー・LED・ボタンをシンプルなAPIで提供**しており、加速度・明るさ・温度・ボタンといった今回必要なセンサーに`import microbit`だけで簡単にアクセスできる。
- **`print()`と`uart`モジュールでUSBシリアル通信が完結**し、PC側のNode.jsブリッジ（`serialport`パッケージなどでシリアルポートを扱う予定）と組み合わせやすい。C++（MakeCode/mbed）に比べて開発サイクルが速く、探求活動としてコードの意味を説明しやすい。
- MakeCode（ブロック/JavaScript）も選択肢だったが、複雑な文字列処理（コマンドのパース、改行区切りのバッファ処理）はPythonの方が素直に書けるため採用した。
